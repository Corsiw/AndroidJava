## Общая информация

- **Язык** — Java (основная часть проектов), Kotlin (Lab9).
- **Минимальная версия SDK** — 26 (Android 8.0), целевой SDK — 36.
- **Сборка** — Gradle 8.13, Android Gradle Plugin 8.13.2, Java 11.
- **Основные библиотеки** — AndroidX, Material Components, ViewModel/LiveData, Room, Retrofit, RecyclerView, Navigation.
- В проектах применяется архитектура **MVVM** (Repository → ViewModel → UI), Fragments, кастомные View и работа с фоновыми потоками.

### Как открыть и запустить проект

1. Клонируйте репозиторий: `git clone https://github.com/Corsiw/AndroidJava.git`
2. В Android Studio выберите **File → Open** и укажите каталог нужного проекта (например, `Ex1` или `Reader`).
3. Дождитесь Gradle sync и запустите конфигурацию на устройстве или эмуляторе (API 26+).

Проекты не зависят друг от друга: каждый содержит собственные `gradlew`, конфигурацию модуля `app` и, где требуется, свои зависимости.

### Внешние сервисы и ключи API

Некоторые проекты обращаются к внешним сервисам:

| Проект | Сервис | Ключ |
|---|---|---|
| Ex1 | OpenWeatherMap | ключ вшит в `WeatherRepository` — работает без настроек, пока действителен |
| Ex5 | NewsAPI.org | ключ вшит в `NewsRepository` — работает без настроек, пока действителен |
| Lab4 | JSONPlaceholder | ключ не нужен |
| Lab10 | Unsplash | требуется свой ключ: добавьте градл-свойство `UNSPLASH_ACCESS_KEY` |
| Lab8 | Firebase | требуется подключить свой Firebase-проект (`google-services.json` и плагин `google-services`) |

Если перечисленные ключи перестанут работать (rate limit или отзыв), подставьте свои — инструкции по регистрации есть на сайтах соответствующих сервисов.

## Проекты

Остальные каталоги репозитория (`Lab1`, `Lab2`, `Lab3`, `Lab6`, `Lab9`) — небольшие учебные упражнения по темам курса.

---

### Ex1 — Погода (MVVM + OpenWeatherMap)

Приложение погоды с поиском города и прогнозом на несколько дней, построенное по MVVM-схеме.

- **Стек**: Retrofit, Gson, ViewModel, LiveData, RecyclerView.
- **Слои**: `api` (клиент и интерфейс сервиса) → `model` (DTO ответов) → `repository` → `viewmodel` → `ui`.
- **Возможности**: текущая погода по геолокации или по названию города (геокодинг OpenWeatherMap), список прогноза по дням в `RecyclerView` с отдельным адаптером.

### Ex2 — Интенты и межэкранная навигация

Практика работы с `Intent`: передача данных между экранами и вызов системных возможностей.

- **Возможности**: explicit-intent с передачей текста и картинки во `SecondActivity` и получением результата обратно через `ActivityResultLauncher`, implicit-intent с пользовательским действием (`com.example.ex2.SEND_DATA`), отправка данных в другие приложения через `ACTION_SEND`, выбор изображения из галереи (`GetContent`).

### Ex3 — Менеджер задач (Room + Fragments)

To-do приложение с локальным хранилищем и полноценным CRUD-циклом на фрагментах.

- **Стек**: Room (Entity, DAO, Database), Repository, ViewModel, Fragments, RecyclerView.
- **Экраны**: список задач, детали задачи, добавление/редактирование — каждый в отдельном фрагменте.
- **Особенности**: разделение на слои Model / Repository / ViewModel / UI, адаптер списка с обновлением через LiveData.

### Ex4 — Рисовалка (кастомное View)

Приложение для рисования пальцем или стилусом на базе собственного `DrawingView`.

- **Кастомное View**: обработка `MotionEvent`, рисование через `Path` и `Paint` в `onDraw`.
- **Инструменты**: выбор цвета и толщины линии, ластик, отмена (undo) и возврат (redo) действий с ограничением истории в 20 шагов.

### Ex5 — Новости (Retrofit + Room-кэш)

Лента новостей с сетевой загрузкой и офлайн-кэшированием.

- **Стек**: Retrofit + OkHttp (кастомный интерцептор User-Agent), Room, ViewModel, Glide, SwipeRefreshLayout.
- **Источник**: NewsAPI.org, топ-заголовки с постраничной подгрузкой.
- **Особенности**: сохранение статей в Room для офлайн-доступа, изображения через Glide, обновление списка свайпом.

### Lab4 — Работа с REST API (JSONPlaceholder)

Классическая работа с REST API: чтение и создание записей.

- **Стек**: Retrofit, ViewModel, Fragments, RecyclerView, SwipeRefreshLayout; сборка на Kotlin DSL (`build.gradle.kts`).
- **API**: `GET /posts` — список записей, `POST /posts` — создание новой записи на jsonplaceholder.typicode.com.
- **Экраны**: список элементов и форма создания, связаны через ViewModel.

### Lab5 — Визуализация сортировок

Интерактивная демонстрация работы алгоритмов сортировки в реальном времени.

- **Алгоритмы**: Quick Sort и Merge Sort, выбор через `Spinner`.
- **Отрисовка**: кастомный `SortView` показывает процесс сортировки поэлементно.
- **Управление**: регулировка скорости `SeekBar`, кнопки генерации массива (100 элементов) и отмены сортировки через `volatile`-флаг; сортировка выполняется в фоновом потоке.

### Lab7 — Счётчик на ViewModel и LiveData

Минимальный пример состояния, переживающего пересоздание Activity.

- **`CounterViewModel`**: счётчик и флаг запуска в `LiveData`, тик через `Handler` на главном потоке.
- **UI**: наблюдение за LiveData через `observe`, старт/остановка счётчика одной кнопкой; состояние сохраняется при повороте экрана.

### Lab8 — Карта и чат (Firebase + osmdroid)

Чат с картой: авторизация пользователей и геопозиция на OpenStreetMap.

- **Firebase**: авторизация (вход и регистрация с обработкой типовых ошибок), сообщения чата в Realtime Database в реальном времени.
- **Карта**: osmdroid (OpenStreetMap) с отображением точек.
- **UI**: экраны `LoginActivity` / `RegisterActivity` / `MapChatActivity`, список сообщений в `RecyclerView`.

### Lab10 — Галерея Unsplash

Просмотр фотографий из Unsplash API.

- **Стек**: Retrofit, адаптер `ImageAdapter` для сетки изображений.
- **API**: `GET /photos` с пагинацией (постраничная подгрузка, 20 фото на страницу), доступ по `Access Key` через `BuildConfig`.
- **Настройка**: добавьте свой ключ в градл-свойство `UNSPLASH_ACCESS_KEY` (см. [Внешние сервисы и ключи API](#внешние-сервисы-и-ключи-api)).

### Reader — Читалка электронных книг

Наиболее объёмный проект: библиотека книг с чтением EPUB и PDF и настройками отображения.

- **Хранилище**: Room — сущность `Book`, библиотека с обложками и метаданными.
- **Форматы**: парсинг EPUB через `epublib`, просмотр PDF через библиотеку PdfViewer.
- **Экраны**: библиотека (`LibraryFragment`), читалка (`ReaderActivity`), настройки (`SettingsFragment`) — размер текста, шрифт, тема (глобально или с переопределением для книги), хранение через `SharedPreferences`.
- **Архитектура**: разделение на `application` (репозиторий), `infrastructure` (база данных, менеджеры, парсеры), `model`, `ui`; Navigation Component, ViewModel для библиотеки и настроек.
